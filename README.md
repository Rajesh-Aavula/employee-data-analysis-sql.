SQL Data Analysis Project

📌 Project Overview
This project demonstrates SQL skills used for analyzing employee and department data.

🛠️ SQL Concepts Used
- SELECT
- WHERE
- GROUP BY & HAVING
- ORDER BY
- Aggregate Functions
- CASE WHEN
- DISTINCT
- UNION / UNION ALL
- Joins
- Subqueries
- CTEs
- Window Functions
- Date Functions
- NULL Handling

📊 Analysis Performed
- Employee salary analysis
- Department-wise salary analysis
- Finding highest and lowest salaries
- Finding employees based on salary conditions
- Ranking employees using window functions
- Joining employee and department data
- Grouping and filtering business data

📂 Files
- "analysis.sql" — Contains all SQL queries used for the analysis.

🎯 Objective
To practice SQL data analysis techniques and demonstrate practical SQL skills for a Data Analyst role.
